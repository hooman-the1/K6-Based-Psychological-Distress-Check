## Commands

- `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` — install dependencies
- `.\.venv\Scripts\python.exe manage.py test` — run the whole suite
- `.\.venv\Scripts\python.exe manage.py test assessments` — run the app tests

## Dependencies

- Dependencies are recorded in `requirements.txt`.
- Ask before adding, removing, or upgrading a dependency.
